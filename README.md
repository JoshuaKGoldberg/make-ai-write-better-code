## Usage

The slides are a [Slidev](https://sli.dev) deck in [`slides.md`](./slides.md).

```shell
pnpm install
pnpm dev
```

Then open <http://localhost:3030>, or <http://localhost:3030/presenter> for presenter mode with speaker notes.

To build a static copy of the deck into `dist/`:

```shell
pnpm build
```
